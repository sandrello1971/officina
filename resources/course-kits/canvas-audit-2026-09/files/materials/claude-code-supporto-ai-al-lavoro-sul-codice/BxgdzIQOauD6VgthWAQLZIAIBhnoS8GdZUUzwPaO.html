CLAUDE.md fatto male

Stesso progetto (piattaforma Officina), scritto senza pensare a cosa un agente deve poter fare con questo file. Wall of text, comandi da indovinare, un'istruzione di deploy sbagliata lasciata "per ora", e un segreto in chiaro.

CLAUDE.md
1# Progetto

2Questo è il progetto principale dell'azienda, è scritto in PHP
3e usa Laravel. Il frontend è in React. Ci sono anche alcuni script
4Python per l'AI. Il database è Postgres ma a volte anche MySQL nei
5vecchi moduli. Cerca di scrivere codice pulito e seguire le best
6practice. Usa sempre i design pattern giusti e scrivi test quando

9composer install && npm install && npm run dev

Perché è fatto male

1Nessun comando eseguibile con certezza. "Prova con --ignore-platform-reqs", "il db si chiama credo" — l'agente non ha modo di distinguere un fatto da un'ipotesi, e ripete gli stessi tentativi a ogni sessione.Perché conta: un agente che deve indovinare i comandi spreca turni e token su tentativi falliti invece di lavorare.
2Informazione contraddetta ma non corretta. Il file dice "git push, Forge fa il resto" e subito dopo ammette che non è più vero. Un'istruzione sbagliata lasciata "per ora" verrà seguita alla lettera.Perché conta: Claude Code non ha modo di sapere quale delle due frasi è quella vera — segue quella che sembra un'istruzione diretta.
3Segreti in chiaro nel file. Una chiave API e una password di ambiente committate in un file che finisce nel repo (e quindi potenzialmente nella history di git, nei fork, negli screenshot).Perché conta: CLAUDE.md è testo di progetto come un altro — le stesse regole su segreti/credenziali si applicano.
4Prosa invece di struttura. "Fai attenzione", "cerca di", "quando possibile": indicazioni non azionabili che non cambiano nessun comportamento concreto dell'agente.Perché conta: regole vaghe non sono seguibili né verificabili — occupano spazio nel contesto senza restituire valore.
5Zero riferimenti a percorsi reali. Nessun file, cartella o modulo citato per nome: l'agente deve esplorare da zero la struttura a ogni sessione invece di partire da una mappa.Perché conta: è esattamente il lavoro che CLAUDE.md dovrebbe evitargli di rifare ogni volta.
Da portare in aula: ognuno di questi difetti è comune perché sembra "scrivere in fretta e andare avanti" — ma un CLAUDE.md scritto così genera più lavoro di rilavorazione di quanto ne risparmi.
